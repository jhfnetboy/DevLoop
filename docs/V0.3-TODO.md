# v0.3 Release TODO

This document is the executable release plan for the first autonomous, bounded
DevLoop. A checkbox is complete only when its listed tests pass; documentation
or a prompt alone is not enforcement.

## 0.3 Scope and Invariants

- [x] **Structured results and transitions.** Define versioned `plan`,
  `implementation`, and `review` result envelopes. Validate untrusted model
  output before changing state. A successful plan creates bounded tasks;
  implementation advances only after host checks; review maps deterministically
  to merge, rework, replan, or a supervisor hold.
- [x] **Provider seam.** Route by role and tier through named providers. Keep
  the CLI adapters as a compatibility path; add a Harness bridge that owns and
  disposes each `SubagentRun` on every path. Fail before side effects when the
  configured provider or capability is absent.
- [x] **Host-enforced write scope.** Compare task changes with `allowedPaths`
  and the forbidden set before the host commits. Reject traversal, absolute
  paths, `.git`, and `.devloop` changes regardless of model instructions.
- [x] **SHA-bound independent review.** Persist the implementation commit SHA,
  send that SHA to the reviewer, require the result to echo it, and reject a
  verdict if the branch moved. Implementer and reviewer identities must differ.
- [x] **Durable journal and recovery.** Append a bounded event for every
  committed state mutation with monotonic revisions. Recover `STATE.json` from
  the journal after a torn or missing snapshot; reject divergent revisions.
- [x] **Real composition test.** In a temporary Git repository, run
  plan → delegate → host scope check/commit → review → merge → goal
  complete. Include negative cases for malformed output, scope escape, stale
  review SHA, timeout, and restart.

## Release Gate

- [x] `pnpm test`, `pnpm build`, and `git diff --check` pass.
- [x] Safe default remains `agentBackend: noop`; opt-in configuration is
  documented and has no placeholder model names.
- [x] Install the packed release candidate in a clean DSH profile and confirm
  that its Cordis patch composes and loads.
- [x] Complete one representative repository task with real provider
  credentials and no operator state edits.
- [x] Update `Changes.md`, `Release.md`, and the README truth table; publish the
  tag only from a clean, reviewed commit.

## Deferred to 0.4

The operator UI, budget dashboard, general API broker, resumable multi-agent
Workflow/Ralph execution, and pstack-style arena/cross-judge mode are 0.4 work.
The 0.3 control plane and safety gates are prerequisites for those features,
not part of the model coordinator.
